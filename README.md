# virtual-os
# 🖥️ Тренажер «Віртуальний робочий стіл»

Навчальна імітація операційної системи в браузері для уроків інформатики. Учні тренуються працювати з робочим столом, вікнами, файлами й папками, контекстними меню, архівами, командним рядком і стандартними програмами — без ризику щось зламати в реальній системі.

Це один файл `index.html`: без встановлення, без сервера, без бібліотек і без інтернету під час роботи.

## 🚀 Запуск

**Локально.** Завантажте `index.html` і відкрийте його у браузері (Chrome, Edge, Firefox, Safari).

**Через GitHub Pages.**
1. Створіть репозиторій і завантажте в нього `index.html` та `README.md`.
2. У репозиторії відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку **main** і папку **/ (root)**, натисніть **Save**.
4. За хвилину-дві тренажер буде доступний за адресою  
   `https://<ваш-логін>.github.io/<назва-репозиторію>/`

## 🔐 Початок роботи

Після завантаження системи (анімація) з'являється екран входу. Введіть будь-який логін: на диску **C:** буде створено папку з вашим іменем, куди переміщується папка **Документи**. Для введення логіну латиницею перемкніть мову кнопкою **УКР/ENG** у правому нижньому куті або комбінацією **Alt+Shift**.

## ✨ Можливості

### Робочий стіл і вікна
- Значки «Комп'ютер», «Документи» (ярлик), «Кошик» (у правому нижньому куті), панель задач із кнопкою «Пуск», піктограмами закріплених програм, відкритими вікнами, індикатором мови, календарем і центром сповіщень.
- Вікна: переміщення, зміна розміру за будь-яку межу, згортання, розгортання, прив'язка до країв екрана (ліва/права половина, розгортання вгорі), перемикач вікон (**Alt+Q** або кнопка «Подання завдань»).
- Вільне розташування значків або автоматичне впорядкування, сортування, розмір значків, шпалери, світла й темна тема.
- Довге натискання на сенсорному екрані замінює праву кнопку миші.

### Файлова система
- Виділення (клік, Ctrl+клік, рамка), перетягування, вирізання, копіювання (у тому числі перетягуванням із Ctrl), вставка, перейменування, видалення до Кошика, відновлення, остаточне видалення з підтвердженням.
- Створення папок, текстових документів, точкових малюнків і ярликів; завантаження файлів із комп'ютера.
- Скасування й повтор дій (**Ctrl+Z / Ctrl+Y**).
- Властивості (тип, розташування, розмір, дати, атрибути «Тільки для читання» і «Прихований»), підказки при наведенні курсору.
- Режими перегляду «Плитки», «Список», «Таблиця», сортування, пошук у папці, навігація «назад / вперед / вгору», ліва панель як у Провіднику з рухомою межею.
- Диски C: і D: із відображенням ємності та вільного місця.
- Захищена папка «Операційна система» з вкладеними папками та файлами, які неможливо змінити.

### Командний рядок
`dir`, `cd`, `C:` / `D:`, `md` / `mkdir`, `rd` (`/s`), `del`, `copy`, `move`, `ren`, `type`, `tree`, `echo`, `find` (`/i /c /n`), `attrib` (`+r -r +h -h`), `start`, `call`, `cls`, `ver`, `date`, `time`, `whoami`, `help`, `exit`.  
Вивід можна перенаправляти у файл: `команда > файл`, `команда >> файл`. Файли `.bat` / `.cmd` запускаються за іменем або подвійним кліком.

## ⚠️ Обмеження

- Файлова система існує лише в пам'яті сторінки: після оновлення сторінки все повертається до початкового стану.
- Файли, завантажені з комп'ютера, доступні лише в поточному сеансі.
- Стиснення в Архіваторі імітоване: файл `.zip` не відкривається зовнішніми програмами.
- Браузер не передає сторінці системні комбінації (Alt+Tab, а в деяких системах і Ctrl+Shift+Esc), тому замість Alt+Tab працює Alt+Q.
- Відтворення медіа залежить від форматів, які підтримує браузер.
